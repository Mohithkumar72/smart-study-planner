# 📚 Smart Study Planner

A simple, attractive, and beginner-friendly web application designed to help college students organize their subjects, prioritize study plans based on exam dates and difficulty, and track their preparation progress.

---

## 🌟 Live Demo
Once GitHub Pages is activated, this project is live at:
👉 **[https://mohithkumar72.github.io/smart-study-planner/](https://mohithkumar72.github.io/smart-study-planner/)**

---

## 🚀 Key Features

- **Dashboard Overview**: Displays total subjects, pending subjects, completed subjects, and total study hours at a glance.
- **Smart Priority Calculation**: Automatically classifies subjects into **High**, **Medium**, or **Low** priority based on:
  - Days remaining until the exam (urgency)
  - Difficulty level (Easy, Medium, Hard)
  - Estimated study hours required
- **Study Progress Tracking**: Mark subjects as completed or pending with an interactive visual progress bar.
- **Persistent Data**: Uses browser `localStorage` so your study plan remains intact even after refreshing the page or closing the browser.
- **Responsive Design**: Works cleanly on both desktop and mobile devices.

---

## 🛠️ Built With

- **HTML5**: Semantic layout and form elements.
- **CSS3**: Modern styling with a clean light theme, blue-purple accents, and responsive layout.
- **JavaScript (ES6)**: Clean DOM manipulation, priority logic, and local storage management.
